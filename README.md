# Бамперы & Бестии

Вертикальный браузерный прототип физической roguelite-аркады: игрок строит пинбол-машину и отбивает ею орущих круглых врагов.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверки:

```bash
npm test
npm run build
```

## Стек

- React 19 — меню, HUD, драфт и экраны результатов.
- PixiJS — игровой рендер, спрайты и VFX.
- Matter.js — физика и столкновения.
- TypeScript + Vite.

## Прототип

- Один стейдж из 10 вручную заданных волн.
- Пять типов врагов и восемь деталей машины.
- Драфт 1 из 3, реролл, «взять всё», лом, перемещение и объединение деталей до третьего тира.
- Два режима раскладки управления и два режима движения флипперов.
- Арт хранится в `public/assets`; игровые параметры — в `src/game/config.ts`.
- Служебные кнопки в верхней панели позволяют выпускать врагов, завершать волну и проверять поражение базы.
