# Бамперы & Бестии

Вертикальный браузерный прототип физической roguelite-аркады: игрок строит пинбол-машину и отбивает ею орущих круглых врагов.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверки:

```bash
npm test
npm run build
```

## Стек

- React 19 — меню, HUD, драфт и экраны результатов.
- PixiJS — игровой рендер, спрайты и VFX.
- Matter.js — физика и столкновения.
- TypeScript + Vite.

## Milestone 2 — «Гаражная кампания»

- Кампания из 10 вручную настроенных арен с разной геометрией, ритмом волн и финальным физическим боссом Главшаром.
- Версионированный локальный профиль: звёзды, монеты, рекорды, настройки и безопасное восстановление повреждённого save.
- Мастерская с коллекцией из 12 деталей, активной колодой из восьми уникальных типов и постоянной прокачкой до 20 уровня.
- Четыре открываемые детали: Притягатель, Карусель, Пружинный псих и Мясорубка — с отдельными механиками, VFX и артами.
- Seeded shuffle-bag драфт, временные T1–T3 объединения, реролл, «взять всё», ремонт и внутризабеговый лом.
- Идемпотентные награды за забег, повторяемые выплаты, unlock-flow и защита от случайных double-click покупок.
- Адаптивные campaign, details, workshop, battle и result экраны для desktop и мобильных viewport.

Контент кампании находится в `src/content/stages.ts`, мета-экономика и сохранение — в `src/meta/profile.ts`, физический бой — в `src/game/GameEngine.ts`. Служебные боевые кнопки существуют только в development-сборке и не могут начислять мета-награды.
